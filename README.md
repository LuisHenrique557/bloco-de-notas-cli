# Bloco de Notas CLI 📝

Aplicação em linha de comando (CLI) desenvolvida em Python para gerenciamento de notas pessoais, aplicando conceitos de **Programação Orientada a Objetos (POO)** e persistência em banco de dados relacional **SQLite**.

---

## 🚀 Funcionalidades

- **Criar Notas:** Cadastro de anotações com título e conteúdo no banco de dados.
- **Listar e Visualizar:** Exibição de notas cadastradas em tabelas estilizadas diretamente no terminal.
- **Ler Nota Específica:** Consulta ao conteúdo detalhado de um registro existente.
- **Excluir Notas:** Remoção segura de registros da base local.
- **Interface Interativa:** Terminal moderno com cores e formatação avançada via biblioteca `rich`.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3** (Módulos POO, Tipagem e Tratamento de Exceções)
- **SQLite 3** (Modelagem Relacional e Persistência Local)
- **Rich** (Formatação de tabelas, painéis e texto estilizado no CLI)
- **Git & GitHub** (Controle de versão e colaboração)
